# Jarvis Android Assistant

This project is a starter Android app inspired by a Jarvis-style AI assistant.

## Features
- Voice input through the device microphone
- Text-to-speech responses
- Basic command handling:
  - "Hello"
  - "What time is it?"
  - "What date is it?"
  - "Open camera"
  - "Open settings"
  - "Open Google"
  - "Open YouTube"
  - "Call <number>"

## Requirements
- Android Studio
- JDK 17+
- Android SDK 34

## Setup
1. Open this project in Android Studio.
2. Let Gradle sync.
3. Connect a device or start an emulator.
4. Click Run.

## Notes
This is a practical starter implementation. To make it more advanced, you can add:
- Dialogflow / OpenAI / Rasa integration
- Weather and smart-home APIs
- Device automation and app launch workflows
- Better wake-word detection
- Personalized voice profiles
